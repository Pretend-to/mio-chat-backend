模型标签流 · 交互规则

        

          

            
1. 输入模型名后按 空格 / Enter / , 即落成一个标签

            
2. 手打任意自定义模型名（不在任何内置清单里也能落地，标紫色）

            
3. 批量粘贴（逗号 / 换行 / 空格 / 分号分隔）一次落成多个标签

            
4. 点「获取模型列表」拉取结果自动落地成标签（标绿色，自动去重）

            
5. 标签 ⨯ 或输入框内 退格 可删除，支持全量清空

          

          
标签流只是“多值文本输入”的展示层，落库仍是干净的 models: string[]。
