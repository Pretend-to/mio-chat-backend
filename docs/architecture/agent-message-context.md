# 服务端 Agent 消息上下文与在线浏览器

服务端 Agent 的 Web 输入、外部渠道、定时唤起及运行中插话使用相同的消息投影。
纯前端 Web Session 的消息格式不变。

## 消息快照

`lib/chat/messageContext.js` 生成 version 3 元数据，并渲染模型可见的 `<message>`：

- `kind`：message、adjustment 或 task。
- source：渠道公开 ID、适配器类型、名称。
- conversation：外部会话 ID、private/group、话题 ID。
- actor：外部用户 ID、显示名。
- message：消息 ID、发送与接收时间、回复关联。
- client（Web）：每标签页 ID、浏览器、系统、设备类型、时区、语言、Origin。
- network（Web）：服务端 socket 认证阶段记录的 IP，沿用部署的反向代理解析。

未提供的可选字段省略。时间渲染为 UTC ISO，与 client.timezone 一起表达用户环境。
IP 表示网络出口，不自动推断城市或实际位置。原始 UA 作为内部元数据保存；模型只看到解析结果。
浏览器上报的时区、语言、标签页 ID 只描述环境，不参与权限判定。

消息正文与属性分开转义，不根据用户正文中的标签跳过包装。数据库保存原始正文和
结构化元数据；当前输入、历史重建和插话检查点复用同一快照，避免重放改变上下文。
工具注入的多模态 context_message 按原始内容恢复，不伪装成用户新输入。

## 在线浏览器

在线浏览器列表是本轮 system 运行时上下文，不属于任何历史用户消息。
`web_console` 在执行时再次检查在线状态与归属。Web 用户只访问自己名下连接；
具有管理员身份的系统／渠道 Agent 可访问系统管理员浏览器，普通渠道身份无此权限。

默认目标依次为：本轮发言的浏览器、唯一正在观察当前 Agent Session 的浏览器、唯一
可访问的在线浏览器。多个候选时要求先 list 再指定 clientId，不任意猜测。
clientId 是当前 socket 连接 ID；内部标签页 ID 在重连后保持，工具也接受它作为显式目标。

浏览器回包必须来自命令目标 socket；断线立即结束待处理调用，超时最多 60 秒。
旧页面同样支持既有 console 协议；刷新到新前端后会补齐稳定标签页 ID、时区与语言。

核心模块改动需要重启后端，前端需重新构建发布。没有新增数据库字段。
